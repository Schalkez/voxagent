### Test Design Rules
- All tests in single file: `test_coverage_phase10_boost.py`
- Grouped by class: `TestPlannerCoverage`, `TestOCREngineCoverage`, `TestAppLauncherCoverage`, `TestWakeWordCoverage`, `TestEarsCoverage`, `TestEyesCoverage`, `TestMarketplaceCoverage`
- Mock ALL external deps (openwakeword, paddleocr, pytesseract, psutil, httpx, Pillow, sounddevice)
- Use `unittest.mock.patch` for import-time mocks, `AsyncMock` for async methods
- Use `tmp_path` fixture for filesystem tests (marketplace install/uninstall)
- No real network calls, no real audio devices

### Key Mock Patterns

**Planner:** Mock `ProviderRegistry.get_llm()` -> mock LLM with `.chat_with_tools()` returning `{"tool": "create_plan", "result": {"steps": [...]}}`

**OCR:** Patch `paddleocr.PaddleOCR` and `pytesseract.image_to_string` at import site within methods, test sync dispatch path

**Ears:** Create Ears with mock config + mock STT provider, mock recorder.read_chunk() to return numpy arrays, mock wake_word_detector.detect() to return True after N calls

**Eyes:** Patch `PIL.ImageGrab.grab()` to return a mock Image, patch `OCREngine` for read_screen_text tests, test `_get_cached_ocr` directly with time manipulation

**Marketplace:** Use `tmp_path` + monkeypatch `_SKILLS_DIR` and `_INSTALLED_MANIFEST`, mock httpx.AsyncClient for search/install_remote/publish
